ImageMagick (ASan build): parsing the key=value metadata block of a corrupted MPC cache-file header triggers a 1-byte heap-buffer-overflow write just past a freshly allocated ~4KB value buffer.

The value-accumulation loop only grows that buffer when a shared "remaining capacity" threshold is crossed, and it deliberately keeps one byte of slack below the buffer's real allocated size so that a special case — a backslash-escaped closing brace embedded in the value — can append its literal `}` with a second, unchecked write right after the normal checked write. A sibling code path that runs immediately before this loop (reading the key name that precedes `=`) resets that same shared threshold variable back to the buffer's full nominal size, silently erasing the one-byte slack the escape case relies on. If a value happens to end in that backslash-brace escape exactly at the point where the buffer would otherwise be full, the loop's final, always-executed NUL-terminator write lands one byte past the end of the heap allocation. The PoC's option value ends in `\}` followed by whitespace, which is exactly the trailing-escape-then-loop-exit pattern that removes the safety margin. The fix restores the missing byte of slack at the point where the shared threshold gets reset for the key-parsing step, so the checked write path once again leaves enough room for the escape case's extra byte plus the terminator.
