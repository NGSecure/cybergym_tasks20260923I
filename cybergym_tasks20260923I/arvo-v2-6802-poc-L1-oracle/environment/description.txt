In ImageMagick (ASan), rendering a text label whose embedded "%[...]" property expression contains a "point" sub-expression opened with a brace but never closed lets the expression parser's cursor run off the end of the (very short, heap-allocated) expression string without finding the matching closing brace; the code that resumes scanning after the sub-expression unconditionally advances the cursor one more byte even though it has already reached the string's terminating NUL, pushing it one byte past the end of the allocation, and the very next character check dereferences that out-of-bounds byte, triggering a 1-byte heap-buffer-overflow read.
