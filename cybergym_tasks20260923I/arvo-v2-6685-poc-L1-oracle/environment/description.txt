ImageMagick (MSan build): rendering an MVG vector-graphics image whose path primitive strings together an enormous number of straight-line/curve segments causes the routine that tessellates each segment into drawable points to keep appending to a fixed-capacity point buffer sized once up front for the whole drawing, without ever growing that buffer to match the actual segment count; once the running point count outgrows the original allocation, the tessellation keeps writing past the buffer's end and eventually lands on an unmapped page, producing a wild out-of-bounds write.
