ImageMagick (MSan build): reading a PNG whose iCCP chunk carries an embedded ICC color profile fetches human-readable description/manufacturer/model/copyright strings from that profile through a color-management library call into a fixed-size stack buffer. When the profile lacks a text entry for the requested language/country tag, the library call reports failure without writing anything into the buffer, leaving it entirely unset; the caller did not check that failure and went on to treat the buffer as if it already held a valid, null-terminated string, storing it into the image's property table. Recording that "string" measures its length, so the uninitialized stack bytes are read, triggering a use-of-uninitialized-value warning.
