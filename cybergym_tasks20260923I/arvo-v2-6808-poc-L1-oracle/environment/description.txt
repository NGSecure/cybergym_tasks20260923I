A bug in ImageMagick (MSan use-of-uninitialized-value) occurs while reading a layered PSD-format image: the decoder allocates the pixel storage for the final composite canvas as soon as its dimensions are known, but that freshly heap-allocated buffer is never explicitly filled with real pixel values before layer merging begins; when the first decoded layer is alpha-blended ("over"-composited) onto this canvas, the blend/clamp step reads the canvas's own pixel channels as the compositing destination, so bytes that were only allocated and never written get consumed as if they held valid pixel data, which MemorySanitizer flags as a read of uninitialized memory. The fix inserts an explicit pixel-reset call right after the canvas is sized, initializing the whole buffer before any layer can be composited onto it, closing the gap between allocation and first real write.
