ImageMagick (MSan build): decoding a crafted VIFF (Khoros Visualization Image File Format) raster image, the pixel-data reader sizes its working buffer using the larger of two header-derived quantities — the image's declared total pixel count and a separate maximum-packet count tied to the row's compression/count fields — but then only ever fills that buffer with the number of bytes the packet-count-sized read from the input stream actually consumes. When the declared pixel count is the larger of the two, the buffer's extra tail (sized to cover that larger count) is left completely unwritten by the read, and a later step that walks the whole buffer according to the declared pixel count — converting the raw sample bytes into the image's internal pixel representation — consumes those never-written bytes, which MemorySanitizer flags as a use-of-uninitialized-value.
