ImageMagick (MSan build): decoding an MNG image chunk whose actual data runs out (truncated input) before as many bytes as the chunk header declared have been supplied lets the byte-fill loop for that chunk's buffer stop silently on EOF, leaving the remainder of the buffer unfilled instead of erroring out; later code that extracts frame/clip box coordinates from the chunk trusts the header's declared length rather than how many bytes were actually filled, so it reads those leftover unfilled bytes as coordinate values, and computing the overlap between two such boxes then reads one of the uninitialized fields, triggering a use-of-uninitialized-value warning.
