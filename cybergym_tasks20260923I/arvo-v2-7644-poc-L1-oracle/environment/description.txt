MemorySanitizer reports a use-of-uninitialized-value while ImageMagick's ping/read pipeline parses an icon-format container whose directory entry marks an embedded sub-image as PNG-encoded. The coder allocates a heap buffer sized to the sub-image's declared byte length, stamps a handful of synthetic header bytes into its front, and then attempts to read the remaining declared length from the input stream — but it hands the buffer to the PNG decoder as fully populated even when the stream yielded fewer bytes than requested. Because the allocator does not zero new memory, the unread tail of the buffer still holds leftover heap contents, and the inner PNG chunk-header parser consumes that leftover memory as if it were a real chunk-length field, tripping the sanitizer on the very first chunk read after the synthetic header.
